LIVE CAMERA SCANNER — HOSTING QUICK START
=========================================

1. Open index.html.
2. Replace API_URL with your Apps Script /exec URL.
3. Upload index.html to an HTTPS static host.
4. GitHub Pages is recommended.
5. Open the published HTTPS URL on Android Chrome.
6. Allow camera permission.
7. Sign in with a Staff ID/PIN.
8. Point the rear camera at the QR.

The QR is detected automatically; no photo button is required.

Do not use the Apps Script /exec?view=checkin URL for this live-camera page.
